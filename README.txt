# Winter Arc — 90 Day Tracker

This is a free, installable Android-friendly Progressive Web App (PWA).

## Put it on your Android phone
1. Upload these files to any free static website host. GitHub Pages is a simple free option.
2. Open the resulting website in Chrome on your Android phone.
3. Use Chrome's menu (⋮) and choose **Add to Home screen** / **Install app**.
4. Open it from the new home-screen icon.

## Important
- Progress is saved locally on the device/browser.
- Use **Backup my progress** inside the app occasionally.
- The tracker is based on the supplied 90-day workbook and starts on September 30, 2026.
